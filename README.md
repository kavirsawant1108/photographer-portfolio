# Photographer Portfolio

> Responsive photography portfolio website built with React and modern frontend animation libraries.

## Overview

A visual portfolio website designed to present photography work through a polished, responsive web experience.

The project demonstrates modern React UI development, animation, routing, and contact-form integration.

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- Framer Motion
- GSAP
- EmailJS
- Tailwind CSS

## Features

- Responsive photography portfolio
- Animated page transitions and interactions
- Client-side routing
- Gallery-focused presentation
- Contact form integration
- Modern responsive UI

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/kavirsawant1108/photographer-portfolio.git
cd photographer-portfolio
npm install
```

### Run Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
